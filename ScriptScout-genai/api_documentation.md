# ScriptScout GenAI API Integration Documentation

This document describes how to integrate the Python GenAI transcription and analysis service into the Spring Boot backend application.

---

## 1. Connection & Endpoint Specifications

### Base URL
* **Development/Tunnel URL:** `https://1e1a90661b718c.lhr.life` *(Note: This is a temporary tunnel URL for local testing)*
* **Production Load Balancer Target:** Refer to the configurations in `terraform/` (e.g. `https://api.scriptscout.com`)

### Endpoint Details
* **Route:** `/upload`
* **HTTP Method:** `POST`
* **Content-Type:** `multipart/form-data`

---

## 2. Request Structure

### Request Headers
No custom headers or API keys are required from the backend caller. The authentication with Google Gemini is handled internally by the Python service using its local configuration.

```http
Content-Type: multipart/form-data
```

### Request Body
The request must contain a single file sent as multipart form data.
* **Form Field Name:** `file`
* **JSON Body:** **Not Applicable** (Do not send any JSON body payload).

---

## 3. Response Structure

Upon successful processing, the API returns an `HTTP 200 OK` status with a JSON object.

### Success Response Fields
| Field Name | Type | Description |
| :--- | :--- | :--- |
| `transcript` | String | Raw text transcribed from the audio/video file via Whisper. |
| `metadata` | String | A JSON-formatted string report generated by Google Gemini. (Contains: `summary`, `genre`, `tags`, `keywords`, `language`, `age_rating`, and `timestamps`). |

### Complete Success Response Example
```json
{
  "transcript": " 1 2 3",
  "metadata": "{\n  \"summary\": \"A short recording of counting the numbers one, two, and three.\",\n  \"genre\": \"Educational\",\n  \"tags\": [\n    \"counting\",\n    \"numbers\",\n    \"basic math\"\n  ],\n  \"keywords\": [\n    \"one\",\n    \"two\",\n    \"three\"\n  ],\n  \"language\": \"English\",\n  \"age_rating\": \"G\",\n  \"timestamps\": [\n    {\n      \"time\": \"00:00\",\n      \"topic\": \"Number One\"\n    },\n    {\n      \"time\": \"00:01\",\n      \"topic\": \"Number Two\"\n    },\n    {\n      \"time\": \"00:02\",\n      \"topic\": \"Number Three\"\n    }\n  ]\n}"
}
```

---

## 4. HTTP Status Codes

| Status Code | Meaning | Cause | Action Required |
| :--- | :---: | :--- | :--- |
| **200 OK** | Success | Request processed, transcription and analysis completed successfully. | Parse the transcript and metadata JSON string. |
| **400 Bad Request** | Invalid File | The uploaded file parameter is missing or invalid. | Verify the multipart field key is set to `"file"`. |
| **502 Bad Gateway / 503 / 504** | Timeout | The public tunnel gateway timed out before Whisper finished transcribing on CPU. | Retry request or configure higher gateway timeout limits. |
| **500 Internal Server Error**| Server Crash | Code execution failure on the Python host. | Check Uvicorn backend execution logs. |

---

## 5. Supported File Types
The endpoint accepts standard audio and video formats, including:
* **Audio:** `.mp3`, `.wav`, `.m4a`, `.ogg`, `.flac`
* **Video:** `.mp4`, `.avi`, `.mkv`, `.mov`

### Example B: Postman Configuration
1. Set HTTP Method to `POST`.
2. Enter URL: `https://1e1a90661b718c.lhr.life/upload`.
3. Under the **Body** tab, select **form-data**.
4. In the **Key** column, type `file` and change the dropdown type to **File**.
5. In the **Value** column, click **Select Files** and upload your audio/video file.
6. Click **Send**.

### Example C: Spring Boot Integration (using WebClient)
```java
import org.springframework.core.io.FileSystemResource;
import org.springframework.http.HttpEntity;
import org.springframework.http.client.MultipartBodyBuilder;
import org.springframework.util.MultiValueMap;
import org.springframework.web.reactive.function.BodyInserters;
import org.springframework.web.reactive.function.client.WebClient;
import reactor.core.publisher.Mono;

import java.io.File;

public class GenAiService {

    private final WebClient webClient = WebClient.builder()
            .baseUrl("https://1e1a90661b718c.lhr.life")
            .build();

    public Mono<GenApiResponse> uploadMono(File mediaFile) {
        MultipartBodyBuilder builder = new MultipartBodyBuilder();
        builder.part("file", new FileSystemResource(mediaFile));
        MultiValueMap<String, HttpEntity<?>> multipartBody = builder.build();

        return webClient.post()
                .uri("/upload")
                .body(BodyInserters.fromMultipartData(multipartBody))
                .retrieve()
                .bodyToMono(GenApiResponse.class);
    }
}
```

### Example D: Spring Boot Integration (using RestTemplate)
```java
import org.springframework.core.io.FileSystemResource;
import org.springframework.http.HttpEntity;
import org.springframework.http.HttpHeaders;
import org.springframework.http.MediaType;
import org.springframework.util.LinkedMultiValueMap;
import org.springframework.util.MultiValueMap;
import org.springframework.web.client.RestTemplate;

import java.io.File;

public class GenAiServiceLegacy {

    private final RestTemplate restTemplate = new RestTemplate();
    private final String uploadUrl = "https://1e1a90661b718c.lhr.life/upload";

    public GenApiResponse uploadMedia(File mediaFile) {
        HttpHeaders headers = new HttpHeaders();
        headers.setContentType(MediaType.MULTIPART_FORM_DATA);

        MultiValueMap<String, Object> body = new LinkedMultiValueMap<>();
        body.add("file", new FileSystemResource(mediaFile));

        HttpEntity<MultiValueMap<String, Object>> requestEntity = new HttpEntity<>(body, headers);

        return restTemplate.postForObject(uploadUrl, requestEntity, GenApiResponse.class);
    }
}
```

### Response DTO Model Class
```java
public class GenApiResponse {
    private String transcript;
    private String metadata; // This can be parsed into a custom metadata object

    // Getters and Setters
    public String getTranscript() { return transcript; }

    public String getMetadata() { return metadata; }
    public void setMetadata(String metadata) { this.metadata = metadata; }
}
```

## 7. Known Constraints & Notes

1. **Gateway/Tunnel Timeouts:** Since Whisper is running on a CPU thread, transcription for larger media files (e.g. over 10 minutes) may take longer than 30 seconds. Public tunnels like `localhost.run` or `serveo.net` may timeout with a `502 Bad Gateway` if execution takes too long.
2. **Metadata Parsing:** The `"metadata"` field in the JSON response is a raw JSON string. If your Spring Boot service needs to query individual properties, parse the string as a nested JSON object.
